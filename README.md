# Кино на вечер

Прототип веб-сервиса для выбора фильма на вечер. Next.js (App Router), без базы данных: каталог читается из `data/movies.json`, постеры лежат в `public/posters/`.

## Страницы

- `/` — каталог: логотип, круглая кнопка фильтров и поиск; справа кнопки «Сохранённые» и переключатель темы. Сверху карусель «Для вас»: до 6 фильмов по оценкам, сохранениям и просмотрам, крупная карточка и край следующей и вопрос «Уже посмотрели?» про последний открытый фильм.
- `/saved` — сохранённые фильмы.
- `/movie/[id]` — страница фильма (id = id Кинопоиска): постер, рейтинги, логлайн, кнопки «Сохранить» и «Трейлер», описание; под описанием лента «В ролях» с карточками актёров, затем «Похожие фильмы» (по общим жанрам, формату, странам и режиссёрам), ниже «Подробности» — плитки «Съёмочная группа», «Контекст и факты», «Награды», «Премьеры и сборы», раскрываются на всю ширину; под ними ссылки на Кинопоиск и IMDb. Оценка одним из трёх: разбитое сердце, сердце, три сердца («Уже смотрели?»). Сохранения, оценки, просмотры и выбранная тема хранятся в localStorage браузера.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Деплой на Vercel (бесплатный план Hobby)

Вариант 1, через GitHub:
1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. На vercel.com нажмите Add New → Project, выберите репозиторий.
3. Vercel сам определит Next.js. Нажмите Deploy, настройки менять не нужно.

Вариант 2, из терминала:
```bash
npm install
npx vercel        # первый раз попросит войти и создаст проект
npx vercel --prod # публикация на постоянный адрес *.vercel.app
```

## Актёры и фото

Состав расширен по Википедии (источник `catalog`), у «Не хороните меня без Ивана» — по титрам плаката (источник `poster`). У актёра может быть поле `wiki` вида `en:Zoey_Deutch`: при сборке на Vercel сервер запрашивает краткую справку Википедии и берёт оттуда фото. Если статьи нет, у неё нет фото или описание не похоже на актёра, показываются инициалы. В статическом превью внешние запросы запрещены, поэтому там всегда инициалы.

## Как добавить фильм

Добавьте запись в `data/movies.json` по той же схеме и положите постер в `public/posters/<kinopoisk_id>.jpg`. Новая страница появится после следующей сборки.

## Структура

```
app/            страницы и глобальные стили
components/     Catalog (фильтры и поиск), MovieCard, MovieDetail, SaveButton, Logo, Icons
lib/            загрузка данных и форматирование (даты, деньги, длительность)
data/           movies.json
public/posters/ постеры
preview/        сборка статической превью-версии тех же компонентов (для деплоя не нужна)
```

## Видео или кадры на фоне шапки фильма

У всех фильмов в `movies.json` уже заполнено `media.trailer_youtube_id` (трейлеры найдены на YouTube 10.10.2026, канал указан в `trailer_youtube_channel`). На Vercel трейлер крутится на фоне шапки без звука; кнопка «Трейлер» открывает его на YouTube. Без видео фон — размытый постер с медленным движением. Если добавить в запись фильма в `movies.json` объект `media`, фон заменится автоматически:

```json
"media": {
  "trailer_youtube_id": "XXXXXXXXXXX",
  "trailer_mp4": "/trailers/6553389.mp4",
  "stills": ["/stills/6553389-1.jpg", "/stills/6553389-2.jpg", "/stills/6553389-3.jpg"]
}
```

Приоритет: mp4, затем YouTube, затем кадры. Видео идёт без звука по кругу и стартует с 5-й секунды (константа `TRAILER_START` в `components/HeroBackdrop.jsx`). Файлы кладутся в `public/`.
